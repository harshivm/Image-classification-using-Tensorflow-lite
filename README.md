"Mobile-Optimized Image Classification System"
 1. Developed a real-time image classification application using TensorFlow Lite for mobile/embedded deployment
 2. Trained and optimized a custom CNN model to recognize 10+ object categories with >85% accuracy

 5. Technologies: Python, TensorFlow, TensorFlow Lite, MobileNet architecture
